Accessibility note

Accessibility matters. This game shows its story as text that fades in and is then removed, which doesn't work for everyone, so screen readers read each line out loud as it appears.

If anything in this game is hard to use with a screen reader, a keyboard or any other assistive technology, please report it to kurt.sell8@gmail.com.
